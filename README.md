# site_pizzattolog_frontend

Frontend do site institucional da Pizzattolog criado com Next.js, TypeScript e Material UI.

## Como executar

```bash
npm install
npm run dev
```

Acesse:

- Site público: http://localhost:3000
- Painel admin: http://localhost:3000/admin

## Painel admin

Use `Configurar primeiro acesso` para criar o primeiro usuário `ADMIN`.
Depois do login, o perfil `MARKETING` acessa textos, fotos e hero. O perfil
`ADMIN` também acessa rotas, cadastro de usuários, edição de usuários, reset de
senha e log de auditoria.
